# Maria Carletto — Academic & Technical Portfolio

Personal portfolio featuring research, projects, professional experience and CV.

## Local development

Requires Node.js 22.12+ (a current patched LTS release is recommended) and npm.

```sh
npm install
npm run dev
npm run test
npm run build
npm run preview
```

Built with React, TypeScript, Vite and Tailwind CSS. All content lives in `src/content/portfolio.ts`. The single-page site has no server or database. Build output is `dist/`.

See [DEPLOYMENT.md](DEPLOYMENT.md) and [SECURITY.md](SECURITY.md).
